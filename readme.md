# Desktop Wallpapers 

<h3 align="left">
Welcome to my wallpapers repository
</h3>

An original collection of wallpapers I generated using prompts in <a href="https://gemini.google.com/app">Gemini</a>. 

Images upscaled using <a href="https://flathub.org/en/apps/org.upscayl.Upscayl">Upscayl</a>.
File sizes optimised using <a href="https://github.com/storytold/photocraft">Photocraft</a>.

Themes include beaches, castles, cows, dinosaurs, ducks, ice-age animals, mountains. 
Some have style variations/revisions, scene variations day/night lighting.

All wallpapers are JPEG, have 21:9 aspect ratios, and are 3440 x 1440px in size.

21:9 aspect is suitable for resolutions:

• 1280 × 540 – Ultrawide SD (rare/basic)

• 2060 × 1080 - (WFHD)

• 3440 × 1440 - (UWQHD)

• 3840 × 1600 - (UWQHD+ / QHD+ )

• 5120 × 2160 - (5K2K Ultrawide)

## Usage

Download and copy to your desktop backgrounds folder. Use your chosen desktop environment to set them as wallpaper.
